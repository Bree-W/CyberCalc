# CyberCalc Forensic & CTF Sample Files

This directory contains sample payloads and header dumps for testing CyberCalc's investigative workbench tools:

1. **`sample_dos_header.hex`**: DOS MZ / PE executable header (`4D 5A 90 00 ...`) for inspecting byte representations.
2. **`sample_png_header.hex`**: Portable Network Graphics 8-byte magic header (`89 50 4E 47 0D 0A 1A 0A ...`).
3. **`sample_shellcode.hex`**: Binary payload for inspecting byte representations.
4. **`sample_repeating_xor.hex`**: Byte sequence available for manual inspection.
